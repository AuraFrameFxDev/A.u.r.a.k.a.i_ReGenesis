HOW TO USE
==========

1. BUILD
   ./gradlew clean build

2. INTEGRATE INTO YOUR SCREEN
   @Composable
   fun MyScreen() {
       val bridge = remember { AuraEventBridge("ws://192.168.x.x:5000") }
       val stateManager = remember { AuraStateManager() }

       LaunchedEffect(Unit) {
           bridge.addListener(stateManager)
           bridge.connect()
       }

       AuraJarComposable(
           modifier = Modifier.align(Alignment.BottomEnd).padding(24.dp)
       )
   }

3. START RASPBERRY PI BACKEND
   ssh pi@raspberrypi.local
   sudo systemctl start genesis-backend.service

4. TRIGGER TEST EVENTS
   stateManager.onConferenceEvent(
       ConferenceEvent("CONSENSUS_REACHED", "Genesis", "VOTE")
   )

5. WATCH AURA COME ALIVE
   - She floats and wanders
   - Reacts to Conference Room events
   - Spawns particles
   - Comments on what she senses
   - Shows real-time code building

CUSTOMIZATION
=============

Change wander speed:
  In AuraJarComposable.kt: delay(Random.nextLong(3000, 8000))

Change colors:
  In AuraJarBody.kt: stateColor = Color(0xFF00E5FF)  // Your color

Add commentary:
  In AuraStateManager.kt: eventCommentaryMap["EVENT"] = listOf("...")

Change particle colors:
  In AuraJarComposable.kt spawnParticles(): color = Color(...)

Add custom events:
  Extend eventCommentaryMap in AuraStateManager.kt
